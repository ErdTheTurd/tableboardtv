Privacy

Draft for review. Describes the app as built today. Update before any public release.

Tableboard TV is built for local play between an Apple TV and nearby iPhones.

  • Traffic stays on your local network (Bonjour / local networking). There is no cloud game server in the app as built.
  • There are no accounts and no cloud login.
  • The app as built does not collect personal data for analytics, advertising, or a remote backend.
  • Player names and colors stay on the devices in that table session.

This website is separate from the app. If you email support@tableboardtv.com, we receive whatever you include in that message so we can reply.

Questions about this draft: support@tableboardtv.com.
